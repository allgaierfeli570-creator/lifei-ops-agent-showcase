# 立菲运营官 · Agent 公开展示站

这是【立菲运营官】的公开能力展示页面，使用 GitHub Pages 发布。

## 重要说明

- 本站只展示 Agent 的岗位、流程、能力边界和模拟体验。
- 所有演示数据均为虚拟数据。
- 不连接 Hermes、飞书、MiniMax、本地文件或任何真实 API。
- 访客无法调用真实 Agent，也不会获得任何权限。

## 本地预览

直接打开 `index.html` 即可预览。页面只依赖静态 HTML、CSS 和 JavaScript。

## GitHub Pages

仓库包含 GitHub Actions 发布工作流。推送到 `main` 后，工作流会将根目录静态文件发布为 GitHub Pages：

`https://你的GitHub用户名.github.io/lifei-ops-agent-showcase/`

## 不应上传的内容

真实 Hermes Profile、飞书凭据、MiniMax Token、`.env`、真实 Excel、真实运行日志和数据导入文件不得进入此仓库。
